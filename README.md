## 🚀 Featured Projects

### 🎙️ Real-Time Voice AI Agent
A voice conversation pipeline combining speech-to-text (Deepgram), an LLM agent (LangGraph), and text-to-speech (ElevenLabs/Vapi). Async task orchestration targets sub-2-second response latency.
**Stack:** Python, FastAPI, LangGraph, Deepgram, ElevenLabs, Vapi

### 🏠 RAG-Based Property Search System
Retrieval-augmented search over a real estate dataset using PostgreSQL + pgvector. Structured filtering and vector similarity search now live in a single database layer, replacing a two-database ChromaDB + SQLite setup.
**Stack:** Python, PostgreSQL, pgvector, LangChain

### 🤖 LangChain-Based AFL Conversational Agent
A retrieval-augmented chat agent (LangChain, Groq-hosted Llama 3.3 70B) with multi-turn memory and guardrails. Includes a structured evaluation of refusal and grounding behavior across legitimate, off-topic, and edge-case prompts.
**Stack:** Python, LangChain, Groq

### 😀 Face Emotion Detection System
Real-time facial emotion recognition (happy, sad, angry, neutral, surprised). Data augmentation and transfer learning with a pretrained model improved generalization on limited data, reaching **89% validation accuracy**. Real-time inference runs through OpenCV with webcam input.
**Stack:** Python, OpenCV, Transfer Learning

### 💬 Echo: AI-Powered Chatbot
A conversational chatbot built on the Gemini API with a Streamlit interface. It handles API-key authentication and session-based conversation state, so context carries across turns. Deployed for live public access.
**Stack:** Python, Gemini API, Streamlit

### 📊 AFL Player & Match Data Pipeline
Cleaned and merged two raw AFL datasets (2,848 player records and 25,491 seasonal stat records). Resolved duplicate rows, coerced malformed ID fields, and imputed missing values with domain-appropriate rules (for example, missing stat counts treated as zero occurrences rather than unknowns). Delivered an analysis-ready dataset with a documented data quality report.
**Stack:** Python, Pandas

### ⚙️ CRM & Scheduling Automation Pipeline
A non-blocking automation layer using n8n and webhook-driven workflows for appointment booking (Google Calendar), confirmation emails (SMTP), and lead tracking. Includes fixes for silent-failure bugs in the integration layer.
**Stack:** n8n, Webhooks, Google Calendar, SMTP
